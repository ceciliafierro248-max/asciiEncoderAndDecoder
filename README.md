# ASCII Encoder and Decoder
This Streamlit app allows to user to encode ASCII images into a copy and paste string and view ASCII art when the user provides a decode string. This project was created as an extension of the Python Essentials Training LinkedIn Learning course and as part of Hack Club Snowflake. I hope you enjoy!
